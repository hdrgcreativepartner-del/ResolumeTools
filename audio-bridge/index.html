Dirancang untuk workflow kreatif

01 / Input media

MP3, WAV, FLAC, AAC, MP4, MOV, MKV, WEBM dan format lain yang didukung FFmpeg.

02 / Kualitas output

Pilih WAV atau FLAC, bit depth 16/24, sample rate dan stereo/mono.

03 / Batch conversion

Tambahkan banyak file atau folder, kemudian tentukan lokasi file hasilnya.

04 / MSI Installer

Instalasi Windows dengan shortcut Start Menu dan FFmpeg yang dibundel.

Cara memasang versi MSI

Unduh artifact MSI dari GitHub Actions yang berhasil, ekstrak ZIP artifact, lalu jalankan file .msi. Instalasi membuat shortcut aplikasi; FFmpeg dibundel sehingga tidak perlu unduhan terpisah.
