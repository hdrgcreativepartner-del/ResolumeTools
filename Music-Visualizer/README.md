# HDRG Music Visualizer 0.5

Windows x64 music player and visual studio, based on the supplied v0.4 visualizer.

## Install

Download **HDRG-Music-Visualizer-0.5.0-x64.msi** from the `music-visualizer-v0.5.0` GitHub Release. The release installer is published only after the Windows build and install/startup/uninstall checks succeed. Windows 10/11 x64. The installer is currently unsigned.

## Player

1. Add multiple audio tracks (MP3, WAV, FLAC, OGG and formats supported by Chromium).
2. Play, pause, seek, adjust volume, search, reorder with ↑, remove tracks, or select sequential/repeat/shuffle.
3. Enable **Auto DJ** for equal-power crossfades of 1–15 seconds. Short tracks use at most one-third of their duration. Last sequential track stops; repeat wraps. Pause, seek and manual next are handled across both decks.
4. **Save library** stores audio copies, lyrics, artwork, templates and settings locally. The saved library is restored on next launch. Save again after changes. Restore replaces the current unsaved queue with the last saved library. This uses disk space; audio is never uploaded.
5. Use the three-band EQ to adjust bass/mid/treble. Media keys and Space control playback.

## Visual Studio

Switch to Studio to upload a logo/background and customize 6 categories × 6 variations inherited from v0.4. Save multiple looks and assign them to a song or all songs. Player mode can use the assigned template, rotate saved templates per song, or choose a category from audio energy. Float particles remain bounded by the frame.

Live Output makes the canvas fullscreen. Record Video records the current song in real time to WebM at 1280×720/30fps, including displayed lyrics and audio; Auto DJ crossfade is suspended while recording. Stop recording to choose the output path. Long recordings consume memory until saved. Native MP4 export, direct Spout/NDI and virtual capture-card drivers are not included. OBS Window Capture can bridge the output to an external routing setup.

## Lyrics

Filename `Artist - Title` provides a starting point; title and artist can be edited. **Find lyrics** queries LRCLIB by title/artist and known duration. Enable auto lookup to query when switching tracks. Only track metadata is sent; no API key is required. Availability depends on the service and exact song/version. Internet failure does not block local playback.

Import `.lrc` for offline synchronized lyrics. Edit text/timestamps, insert the current playback timestamp, export LRC, and adjust offset (positive delays the lyrics). Plain lyrics are shown in the lyrics panel; only timestamped lines appear in fullscreen/recording. This is line-synced display, not word-level karaoke. No AI vocal transcription is bundled.

## Auto DJ scope

This release supports automatic queue playback and crossfade. It does not change BPM, detect musical phrases, match keys, normalize loudness or separate vocals. It is not advertised as beatmatching. Those remain future work.

## Build

Install Node.js 22 LTS on Windows. Run `npm ci`, `npm test`, `npm run build:win`, or use `BUILD-INSTALLER-WINDOWS.bat`. Only MSI x64 is built. Keep appId and MSI upgradeCode stable for future upgrades. GitHub Actions builds and tests the installer before publishing the MSI asset. Source archives auto-generated by GitHub are source code, not installer packages.
