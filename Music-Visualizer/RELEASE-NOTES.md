Windows x64 MSI installer only, based on HDRG Music Visualizer v0.4.

- Player / Studio modes, 36 reactive visual variations, per-song style templates.
- Multi-track playlist, search, reorder, sequential/repeat/shuffle and offline library save/restore.
- Auto DJ equal-power crossfade (1–15 seconds), three-band EQ and media keys.
- LRCLIB lookup, offline LRC import/edit/export, sync offset and lyrics on visual output.
- Fullscreen output and real-time WebM recording retained.

Auto DJ is crossfade, not beatmatching. No AI lyric transcription, direct NDI/Spout, virtual capture driver, or MP4 encoder is bundled. Installer is unsigned. Use Save library to retain playlist changes between sessions.
