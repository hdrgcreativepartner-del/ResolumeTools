THE CONVERSION WORKFLOW

Dari file asli ke editable AI.

CDR → PDF VEKTOR → AI
01

Ekspor dari CorelDRAW

Buka salinan CDR. Pilih File → Publish to PDF. Pada pengaturan teks, aktifkan Export all text as curves. Gunakan PDF modern yang mendukung transparansi; hindari preset yang meratakan transparansi.

Matikan opsi ekspor complex fills sebagai bitmap jika tersedia. Ekspor hanya halaman yang dibutuhkan.

02

Jalankan di Illustrator

Pilih File → Scripts → Other Script, buka skrip HDRG. Pilih satu atau beberapa PDF, lalu folder output. Masukkan nomor halaman untuk setiap PDF, misalnya 1-3,5.

Nomor halaman mengikuti urutan halaman PDF, bukan label halaman CDR.

03

Periksa hasilnya

Buka AI hasil ekspor. Periksa bentuk huruf, warna, clipping, transparansi, dan ukuran artboard. Gunakan Outline View untuk memeriksa path.

Laporan mencatat hasil per halaman, jumlah path, teks tersisa dan bitmap untuk membantu pemeriksaan manual.

Ketahui batas konversinya.

Apakah desain akan menjadi satu gambar?

Skrip membuka PDF sebagai dokumen dan menyimpan AI tanpa perintah flatten. Namun efek khusus CorelDRAW bisa berubah atau menjadi bitmap saat ekspor PDF. Foto asli tetap bitmap. Kesetiaan semua efek dan struktur layer belum dijamin.

Bagaimana jika font hilang?

Pasang font yang sesuai sebelum membuka dan mengekspor CDR. Convert to curve tidak dapat mengembalikan bentuk font yang sudah terganti. Checklist ini tidak mendeteksi font secara otomatis.

Apakah bisa langsung mengunggah CDR?

Belum. Halaman GitHub Pages ini menyediakan toolkit desktop. Tidak ada server konversi atau koneksi otomatis ke CorelDRAW di PC kamu.

Bagaimana dengan dokumen multipage?

Skrip membuat satu AI untuk setiap nomor halaman yang kamu masukkan. Periksa jumlah halaman PDF terlebih dahulu. Menggabungkan semua halaman menjadi satu AI multi-artboard belum tersedia.
