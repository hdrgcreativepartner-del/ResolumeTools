# HDRG Camera v0.5 — Engineering Beta

Based on the HDRG Camera Pro development specification. **This build is not yet a finished v0.5 Pro release.**

## Implemented
- Camera2 normal video / optional microphone and camera front/rear
- Preview and recording surfaces in the active session; foreground notification on background recording
- Timelapse by MediaRecorder capture-rate presets (1/2/5/10/30 sec)
- 720p/1080p/4K requests with fallback based on camera device capabilities
- Video stabilization request where Camera2 reports support
- 3×3 composition overlay
- Internal gallery and playback
- Recording phase state and duplicate start/stop guards

## Not yet implemented or validated
- True frame-counted timelapse and custom intervals (0.5/15/60 seconds)
- Dynamic FPS UI, bitrate panel, actual output duration calculations
- Manual Pro controls (ISO, shutter, manual WB/focus), AE/AF lock, tap-to-focus, pinch-zoom
- 4×4 grid, safe-frame, center-crosshair, horizon sensor
- Gallery share, delete, metadata, filters, latest thumbnail, proper thumbnail grid
- Encoder-level recovery after abrupt process kill
- Preview/video orientation matrix and stabilization result verification on devices

## High-priority technical risks
- Camera2 recorder surface + preview reconfiguration during activity backgrounding is device-dependent.
- Camera preview and foreground recording service are still separate owners during idle/start transition; need a unified camera controller.
- Android 8/9 recordings remain in the app-specific directory.
- APK from GitHub Actions is debug signed. No signed production release without keystore.

## Manual test procedure
1. Install the debug APK on a noncritical Android test device.
2. Grant camera/microphone/notification permission, record a 60-second normal clip with preview visible.
3. Inspect playback and duration in internal gallery.
4. Record while switching apps and while locking screen. Confirm persistent notification and stop control.
5. Capture 1s/5s timelapse and inspect file duration using MediaInfo/ffprobe.
6. Test front and rear cameras, grid, stabilization, and repeated start/stop.
7. Keep a backup of any meaningful recordings; do not use this beta as sole event recorder.

The final v0.5 Pro label is withheld until the specification's core architecture and physical-device tests pass.
