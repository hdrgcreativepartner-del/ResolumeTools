# HDRG Cam 0.6.2 RC3

Based on ResolumeTools main 6806c14; preserves Camera2 + native TextureView, MediaRecorder, and existing manual controls. UI direction follows the supplied HTML reference, implemented as native Android views.

## Changes
- HDRG Cam name and supplied HDRG blue adaptive launcher icon.
- Preview preserves sensor aspect ratio; grid limited to that viewfinder. Display rotation is applied separately from the sensor transform already provided by TextureView.
- Floating compact toolbar; direct Video/Timelapse selector; blue timelapse shutter; white ring with separate red stop square; haptic/press feedback; responsive landscape side panel.
- Scrollable PRO bottom sheet; native gallery with recycled rows, asynchronous scaled thumbnails, 8 MB cache, bounded thumbnail queue, internal video playback and playback cleanup.
- Camera handoff waits for CameraDevice.onClosed instead of 350 ms; stale callback guards; PRO/stabilizer changes update the idle repeating request without reopening the camera.
- UI polling stops in background; pause-aware timer lives in service; recording orientation metadata; ongoing notification reopens app; explicit background control; bounded partial wake lock and storage/time limits.
- Local recordings remain accessible after gallery export failures.
- CI no longer overwrites the old v0.5 release on every branch push.

## Validation actually performed
- Kotlin 2.0.21/JDK 17 compilation against Android API 35.
- Android aapt2 resource/manifest linking and D8 dex build, minimum API 26.
- 69 JVM camera geometry cases, including portrait, landscape, tablet sensors and all four display rotations.
- APK ZIP integrity, zip alignment, and v1/v2 signatures verified for the delivered RC package.
- Source diff whitespace checks.

Gradle plugin resolution was unavailable in this execution environment. The delivered APK was built with build-sdk.sh using official Android tools and the Kotlin compiler. The Gradle project remains available for Android Studio/CI.

## Distribution
The directly delivered RC3 APK uses applicationId com.hdrg.camera.rc1, versionCode 8 and the same TEST-ONLY certificate as the earlier RC2 APK. It updates RC2; the older com.hdrg.camera beta can remain installed. Signing key is outside this repository. These are test builds, not production signing credentials. Standard Gradle debug builds use the repository applicationId and the builder's debug certificate; they are not interchangeable with the signed RC download.

## Device validation still required
This environment has no attached Android device. Installation, physical camera preview, microphone, recording/timelapse duration, pause/resume, front/back, stabilization, background/screen-off, thermal behavior, and actual visual layout have NOT been validated on hardware. Recording still changes camera sessions when the preview is detached/attached, so device-specific transition interruptions remain a risk.

Test: install over RC2; verify portrait and landscape preview/grid; record 15 s with audio; pause/resume; stop/save/play internally; repeat timelapse for at least 90 s; switch lenses; test manual ISO+shutter together; background and reopen; screen-off and restore; deny microphone and use silent video. Keep this PR draft until physical-device tests pass.
